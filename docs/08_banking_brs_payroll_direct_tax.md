# 08_banking_brs_payroll_direct_tax.md — Banking Integrations, BRS Engine, Payroll & Direct Taxation (TDS/TCS)

## 1. Executive Summary & Module Scope
This specification defines the backend business logic and database functions for three critical financial modules in Ledgify[cite: 1, 2]:
1. **Connected Banking & Automated BRS:** Ingesting bank e-statements, calculating automated Bank Reconciliation Statement (BRS) matches via PostgreSQL Trigram similarity (`word_similarity`), and generating 1-click accounting vouchers for un-reconciled bank statement lines[cite: 1, 2].
2. **Direct Taxation (TDS & TCS):** Section 194Q high-value purchase tracking, TCS accrual/receipt processing under Section 206C, and automated export data generation for quarterly Form 26Q and Form 27EQ filings[cite: 1, 2].
3. **Payroll Engine & Statutory Dues:** Employee master management, pay-head structures (Basic, HRA, Special Allowance), attendance tracking, standard tax regime calculations (New vs. Old regime), and export reporting for Form 16 and Form 24Q (Annexure II)[cite: 1, 2].

## 2. Connected Banking & Automated BRS Engine

### 2.1 Bank Statement Import & Data Ingestion
The system ingests CSV, Excel, or PDF bank statements mapped directly to the `bank_statements_brs` table[cite: 1, 2]. Each line is categorized into deposits (Receipts/Inward credits) or withdrawals (Payments/Outward debits).

### 2.2 PostgreSQL Automated Reconciliation Function (Trigram BRS Matching)
This function scans un-reconciled bank statement entries against un-reconciled bank ledger vouchers within the same business tenant, scoring similarity using `word_similarity` over reference numbers, party descriptions, and transaction remarks[cite: 1, 2].

```sql
CREATE OR REPLACE FUNCTION public.auto_reconcile_bank_statement(
    p_business_id UUID,
    p_bank_account_id UUID
)
RETURNS TABLE (
    statement_id UUID,
    matched_voucher_id UUID,
    similarity_score REAL,
    reconciliation_action VARCHAR(20)
)
LANGUAGE plpgsql AS $$ DECLARE     rec RECORD;     v_target_voucher_id UUID;     v_score REAL; BEGIN     FOR rec IN          SELECT bs.id, bs.transaction_date, bs.description, bs.cheque_reference_no,                 bs.withdrawal_amount, bs.deposit_amount         FROM public.bank_statements_brs bs         WHERE bs.business_id = p_business_id           AND bs.bank_account_id = p_bank_account_id           AND bs.is_reconciled = FALSE     LOOP         -- Search matching voucher line item within a 7-day window and identical amount         SELECT              v.id,             GREATEST(                 similarity(v.narration, rec.description),                 word_similarity(COALESCE(rec.cheque_reference_no, ''), COALESCE(v.reference_number, ''))             ) AS match_score         INTO v_target_voucher_id, v_score         FROM public.vouchers v         JOIN public.voucher_line_items vli ON vli.voucher_id = v.id         JOIN public.bank_accounts ba ON ba.ledger_id = vli.account_id         WHERE v.business_id = p_business_id           AND ba.id = p_bank_account_id           AND v.voucher_date BETWEEN (rec.transaction_date - INTERVAL '7 days') AND (rec.transaction_date + INTERVAL '7 days')           AND (               (rec.withdrawal_amount > 0 AND vli.entry_type = 'Cr' AND vli.amount = rec.withdrawal_amount)               OR               (rec.deposit_amount > 0 AND vli.entry_type = 'Dr' AND vli.amount = rec.deposit_amount)           )         ORDER BY match_score DESC         LIMIT 1;          IF v_target_voucher_id IS NOT NULL AND v_score >= 0.60 THEN             -- Update statement record with match candidate             UPDATE public.bank_statements_brs             SET matched_voucher_id = v_target_voucher_id,                 trgm_similarity_score = v_score,                 is_reconciled = (CASE WHEN v_score >= 0.85 THEN TRUE ELSE FALSE END)             WHERE id = rec.id;              statement_id := rec.id;             matched_voucher_id := v_target_voucher_id;             similarity_score := v_score;             reconciliation_action := (CASE WHEN v_score >= 0.85 THEN 'AUTO_RECONCILED' ELSE 'SUGGESTION' END);             RETURN NEXT;         END IF;     END LOOP; END; $$;
2.3 1-Click Voucher Posting from Un-Reconciled Bank LinesFor bank fees, interest credits, or unmatched direct vendor payments, a stored procedure creates the double-entry voucher directly from the statement line.  SQLCREATE OR REPLACE FUNCTION public.create_voucher_from_bank_line(
    p_business_id UUID,
    p_statement_id UUID,
    p_contra_account_id UUID, -- Expense ledger for charges, Party ledger for transfers
    p_voucher_type VARCHAR(20) -- 'Payment', 'Receipt', or 'Contra'
)
RETURNS UUID LANGUAGE plpgsql AS $$ DECLARE     v_stmt RECORD;     v_voucher_id UUID;     v_vtype_id UUID;     v_bank_ledger_id UUID;     v_amt NUMERIC(15, 2); BEGIN     SELECT bs.*, ba.ledger_id INTO v_stmt     FROM public.bank_statements_brs bs     JOIN public.bank_accounts ba ON ba.id = bs.bank_account_id     WHERE bs.id = p_statement_id AND bs.business_id = p_business_id;      IF NOT FOUND THEN         RAISE EXCEPTION 'Bank statement entry not found.';     END IF;      -- Lookup voucher type ID     SELECT id INTO v_vtype_id FROM public.voucher_types      WHERE business_id = p_business_id OR is_system_default = TRUE        AND name = p_voucher_type LIMIT 1;      v_amt := GREATEST(v_stmt.withdrawal_amount, v_stmt.deposit_amount);      -- Insert Voucher Header     INSERT INTO public.vouchers (         business_id, voucher_type_id, voucher_number, voucher_date,          narration, reference_number     ) VALUES (         p_business_id, v_vtype_id, 'BNK-GEN-' \vert{}\vert{} SUBSTRING(gen_random_uuid()::text, 1, 8),         v_stmt.transaction_date, v_stmt.description, v_stmt.cheque_reference_no     ) RETURNING id INTO v_voucher_id;      -- Insert Line Items based on Withdrawal vs Deposit     IF v_stmt.withdrawal_amount > 0 THEN         -- Payment: Debit Contra Account, Credit Bank Ledger         INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)         VALUES (p_business_id, v_voucher_id, p_contra_account_id, 'Dr', v_amt);                  INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)         VALUES (p_business_id, v_voucher_id, v_stmt.ledger_id, 'Cr', v_amt);     ELSE         -- Receipt: Debit Bank Ledger, Credit Contra Account         INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)         VALUES (p_business_id, v_voucher_id, v_stmt.ledger_id, 'Dr', v_amt);                  INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)         VALUES (p_business_id, v_voucher_id, p_contra_account_id, 'Cr', v_amt);     END IF;      -- Mark Bank Statement as Reconciled     UPDATE public.bank_statements_brs     SET is_reconciled = TRUE, matched_voucher_id = v_voucher_id, trgm_similarity_score = 1.0     WHERE id = p_statement_id;      RETURN v_voucher_id; END; $$;
3. Direct Taxation (TDS Section 194Q & TCS Rules)3.1 Statutory RulesTDS on Purchase of Goods (Section 194Q): Applies to buyers whose turnover $> ₹10\text{ Crore}$ in the preceding financial year. Mandatory deduction of 0.1% (or 5% if party has no PAN) on aggregate purchases exceeding ₹50 Lakhs from a resident seller within the financial year.  TCS on Sale of Goods (Section 206C(1H)): Mandatory collection of 0.1% on aggregate receipts exceeding ₹50 Lakhs (if Section 194Q is not deducted by buyer).  3.2 Automated TDS Deduction Stored ProcedureSQLCREATE OR REPLACE FUNCTION public.process_section_194q_tds(
    p_business_id UUID,
    p_voucher_id UUID,
    p_party_account_id UUID,
    p_purchase_amount NUMERIC(15, 2)
)
RETURNS NUMERIC(15, 2) LANGUAGE plpgsql AS $$ DECLARE     v_party_pan VARCHAR(10);     v_ytd_purchases NUMERIC(15, 2) := 0.00;     v_tds_rate NUMERIC(5, 3) := 0.001; -- 0.1\% default     v_taxable_excess NUMERIC(15, 2) := 0.00;     v_tds_amount NUMERIC(15, 2) := 0.00;     v_threshold NUMERIC(15, 2) := 5000000.00; -- ₹50 Lakhs BEGIN     SELECT party_pan INTO v_party_pan FROM public.accounts WHERE id = p_party_account_id;      -- If PAN missing, higher rate under Section 206AA applies (5\%)     IF v_party_pan IS NULL OR LENGTH(v_party_pan) <> 10 THEN         v_tds_rate := 0.05;     END IF;      -- Calculate Year-to-Date (YTD) purchases for this vendor     SELECT COALESCE(SUM(vli.amount), 0.00) INTO v_ytd_purchases     FROM public.voucher_line_items vli     JOIN public.vouchers v ON v.id = vli.voucher_id     WHERE v.business_id = p_business_id       AND vli.account_id = p_party_account_id       AND vli.entry_type = 'Cr'       AND v.voucher_date >= (DATE_TRUNC('year', CURRENT_DATE));      IF (v_ytd_purchases + p_purchase_amount) > v_threshold THEN         IF v_ytd_purchases >= v_threshold THEN             v_taxable_excess := p_purchase_amount;         ELSE             v_taxable_excess := (v_ytd_purchases + p_purchase_amount) - v_threshold;         END IF;          v_tds_amount := ROUND((v_taxable_excess * v_tds_rate), 2);          -- Record TDS Entry for Form 26Q reporting         INSERT INTO public.tds_tcs_entries (             business_id, voucher_id, section_code, party_pan,             assessed_amount, tds_tcs_rate, tax_amount, form_type         ) VALUES (             p_business_id, p_voucher_id, '194Q', COALESCE(v_party_pan, 'PANNOTAVBL'),             v_taxable_excess, v_tds_rate, v_tds_amount, '26Q'         );     END IF;      RETURN v_tds_amount; END; $$;

Payroll Engine & Statutory Reports4.1 Monthly Salary Processing PipelineThe payroll module calculates monthly gross salary, provident fund ($PF = 12\%$ of Basic capped at statutory limits), employee state insurance ($ESI = 0.75\%$ employee, $3.25\%$ employer), and TDS on salaries under Section 192 (New vs. Old tax regimes).  SQLCREATE OR REPLACE FUNCTION public.process_monthly_payroll_voucher(
    p_business_id UUID,
    p_employee_id UUID,
    p_salary_month DATE -- e.g., '2026-08-01'
)
RETURNS UUID LANGUAGE plpgsql AS $$ DECLARE     v_emp RECORD;     v_gross_salary NUMERIC(15, 2);     v_pf_deduction NUMERIC(15, 2) := 0.00;     v_net_payable NUMERIC(15, 2);     v_voucher_id UUID;     v_vtype_id UUID;     v_sal_exp_ledger UUID;     v_sal_pay_ledger UUID;     v_pf_ledger UUID; BEGIN     SELECT * INTO v_emp FROM public.employees_payroll      WHERE id = p_employee_id AND business_id = p_business_id;      v_gross_salary := v_emp.basic_salary + v_emp.hra + v_emp.special_allowance;      IF v_emp.pf_applicable THEN         -- 12\% PF on Basic         v_pf_deduction := ROUND((v_emp.basic_salary * 0.12), 2);     END IF;      v_net_payable := v_gross_salary - v_pf_deduction;      -- Lookup accounts for posting     SELECT id INTO v_sal_exp_ledger FROM public.accounts WHERE business_id = p_business_id AND name = 'Salary Expense' LIMIT 1;     SELECT id INTO v_sal_pay_ledger FROM public.accounts WHERE business_id = p_business_id AND name = 'Salaries Payable' LIMIT 1;     SELECT id INTO v_pf_ledger FROM public.accounts WHERE business_id = p_business_id AND name = 'PF Payable' LIMIT 1;     SELECT id INTO v_vtype_id FROM public.voucher_types WHERE (business_id = p_business_id OR is_system_default = TRUE) AND name = 'Journal' LIMIT 1;      -- Insert Journal Voucher     INSERT INTO public.vouchers (         business_id, voucher_type_id, voucher_number, voucher_date, narration     ) VALUES (         p_business_id, v_vtype_id, 'PAY-' \vert{}\vert{} TO_CHAR(p_salary_month, 'YYMM') \vert{}\vert{} '-' \vert{}\vert{} v_emp.employee_code,         (p_salary_month + INTERVAL '1 month - 1 day')::DATE,         'Salary provision for employee ' \vert{}\vert{} v_emp.full_name \vert{}\vert{} ' (' \vert{}\vert{} v_emp.employee_code \vert{}\vert{} ')'     ) RETURNING id INTO v_voucher_id;      -- Line Items: Dr Salary Expense (Gross), Cr Salaries Payable (Net), Cr PF Payable     INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)     VALUES (p_business_id, v_voucher_id, v_sal_exp_ledger, 'Dr', v_gross_salary);      INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)     VALUES (p_business_id, v_voucher_id, v_sal_pay_ledger, 'Cr', v_net_payable);      IF v_pf_deduction > 0 THEN         INSERT INTO public.voucher_line_items (business_id, voucher_id, account_id, entry_type, amount)         VALUES (p_business_id, v_voucher_id, v_pf_ledger, 'Cr', v_pf_deduction);     END IF;      RETURN v_voucher_id; END; $$;

Direct Tax & Payroll Compliance ExportsForm 26Q (Quarterly TDS Statement): Aggregates Section 194Q records from tds_tcs_entries, outputting mandatory columns (Deductee PAN, Name, Date of Payment, Amount Paid, TDS Deducted, Challan BSR Code, Challan Date).  Form 27EQ (Quarterly TCS Statement): Aggregates Section 206C collection entries.  Form 24Q (Annexure II - Annual Salary TDS): Aggregates monthly payroll registers and computes annual tax liability under Section 192 (reflecting standard deductions and Section 87A rebates under current Finance Act provisions).  Form 16 Part A & B Generator: Emits standard PDF certificate templates summarizing quarterly tax deductions and gross salary breakdowns[cite: 2].
